# Secure Log Storage

The C&C subsystem SHALL store log files containing anomaly detection events as well as detection and observation data originating from endpoint monitoring agents on nodes located within the same trust boundary as the C&C subsystem.

In the shipped deployment the Wazuh manager logs (bind-mounted under `/srv/wazuh/manager/`, see `radar/volumes.yml`) and the Wazuh indexer data (volume `wazuh-indexer-data`, see `radar/docker-compose.core.yml`), which hold the alerts, archived events and the anomalies reported by SONAR and RADAR, reside on the C&C host. When RADAR is attached to an existing Wazuh installation, keeping its storage within the C&C trust boundary is the operator's responsibility.

### Rationale
To ensure confidentiality and integrity with respect to adversaries.
