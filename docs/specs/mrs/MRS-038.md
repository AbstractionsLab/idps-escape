# pcap Support

IDPS-ESCAPE SHOULD capture network traffic using a pcap-based API.

### Rationale
To ensure reuse, wide adoption and known standards-based arguments.

## Planned extensions

> **Status: planned.** Not implemented as of v2.2.0. The extensions below specify intended behaviour; no code implements them yet.

The documented Suricata deployment (`docs/manual/custom_deployments/suricata/`) captures traffic with AF_PACKET by default; its `suricata.yaml` has a `pcap:` section that switches capture to Suricata's libpcap mode, as described in `docs/manual/custom_deployments/suricata/suricata_installation.md`. No shipped configuration uses pcap-based capture by default.
