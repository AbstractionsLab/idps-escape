# XDR & SIEM Integration

The IDPS-ESCAPE system architecture SHALL include an XDR & SIEM subsystem, i.e., a security information and event management (SIEM) and extended detection and response (XDR) platform collecting, correlating and presenting host and network detections.

### Rationale
To ingest data from tools in an  security technology stack to create greater context for Security Operations Center (SOC) teams to perform faster threat detection, investigation, and response.


### Acceptance criteria
Successful validation according to the corresponding test case specification
