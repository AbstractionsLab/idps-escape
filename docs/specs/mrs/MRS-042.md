# SONAR production anomaly detection system

The IDPS-ESCAPE system architecture SHALL include SONAR (SIEM-Oriented Neural Anomaly Recognition) as the primary production multivariate anomaly detection subsystem, superseding ADBox v1 (MTAD-GAT) which remains in maintenance mode for backward compatibility.

### Rationale
SONAR provides improved detection capabilities through pluggable detector backends (by default Microsoft's multivariate anomaly detector, MVAD), integrates with Wazuh by reporting anomalies to the Wazuh manager so that Wazuh rules raise them as alerts (with optional storage in data streams of the Wazuh indexer), includes a debug mode for offline development, measures its detection quality against labelled data, and provides a more maintainable architecture using dataclasses and typed Python. ADBox v1 remains available for existing deployments and specific use cases requiring MTAD-GAT algorithms, but new deployments should use SONAR.

### Key differences

| Aspect | SONAR (Production) | ADBox v1 (Maintenance) |
|--------|-------------------|------------------------|
| **Algorithm** | Pluggable: Microsoft MVAD (graph-attention network, `time-series-anomaly-detector`; default), `pca`, `ewma` baseline | MTAD-GAT (PyTorch) |
| **Status** | Active development | Maintenance only |
| **Integration** | Events to the Wazuh manager (SONAR alerts); optional Wazuh indexer data streams | OpenSearch direct |
| **Configuration** | YAML scenarios | Use-case YAML |
| **Testing** | Debug mode with synthetic data | Requires live Wazuh |
| **CLI** | `poetry run sonar` | `./adbox/adbox.sh` |

### Related requirements
- MRS-004: Multivariate Anomaly Detection (parent requirement)
- MRS-030: Deep Learning Technique (implemented by SONAR)
- MRS-032: Host and Network Ingestion (SONAR ingests from Wazuh)
- MRS-039: Offline AD (SONAR debug mode)
- MRS-041: Standalone AD Subsystem (SONAR runs independently)

### Acceptance criteria
Successful validation according to the corresponding test case specification, including:
- SONAR can train models using historical Wazuh alerts
- SONAR can detect anomalies in real-time, batch, or historical modes
- SONAR reports anomalies to the Wazuh manager, which raises them as Wazuh alerts, and can store them in Wazuh indexer data streams
- SONAR debug mode enables offline testing without Wazuh
- Documentation clearly distinguishes SONAR from ADBox v1
