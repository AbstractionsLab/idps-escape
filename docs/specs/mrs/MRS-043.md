# Detection as Code

RADAR detection logic shall be managed as versioned code artifacts under Git, with changes developed, reviewed, and deployed through a CI/CD pipeline.

### Rationale

To ensure the following properties: full audit trail of every ruleset change through version history, peer review and quality gates via pull requests, automated conflict detection preventing rule ID collisions, consistent and reproducible deployments without direct server access, rollback capability through standard git revert, and collaborative detection engineering across distributed teams.

### Acceptance criteria

Successful validation according to the corresponding test case specification
