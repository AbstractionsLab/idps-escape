# Secure pcap Storage

> **Status: planned.** Not implemented as of v2.2.0. This item specifies intended behaviour; no code implements it yet.

The C&C subsystem SHALL store pcap files (if any) on nodes located within the same trust boundary as the C&C subsystem.

No pcap files are produced: the documented Suricata configuration (`docs/manual/custom_deployments/suricata/suricata.yaml`) ships with `pcap-log` disabled, and no IDPS-ESCAPE component stores packet captures.

### Rationale
To ensure confidentiality and integrity with respect to adversaries.

Successful validation according to the corresponding test case specification
