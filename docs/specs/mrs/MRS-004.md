# Multivariate Anomaly Detection

The IDPS-ESCAPE system architecture SHALL include a multivariate anomaly detection (AD) subsystem to detect anomalies across at least two features/dimensions in at least one of the following types of security event capturing data sets: host-based and network-based.

**Implementation:** This requirement is fulfilled by:
- **SONAR** (primary/production): SIEM-Oriented Neural Anomaly Recognition using Microsoft MVAD library (see MRS-042)
- **ADBox v1** (maintenance): Legacy MTAD-GAT implementation maintained for backward compatibility

### Rationale
To detect deviations from an a priori normal baseline system behavior, possibly caused by malicious actors. SONAR provides modern anomaly detection capabilities with better Wazuh integration, while ADBox v1 remains available for existing deployments.

### Acceptance criteria
Successful validation according to the corresponding test case specification
