# API data retrieval

The AD subsystem SHALL retrieve its input data through the API of the IDPS-ESCAPE SIEM data store, i.e., the Wazuh indexer (OpenSearch) REST API.

### Rationale
To provide consolidated raw data capturing host and network level data for detecting anomalies.
