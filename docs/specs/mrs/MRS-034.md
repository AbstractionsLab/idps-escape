# Standardized AD output

The AD subsystem SHALL output anomaly detection events in a machine-readable format (e.g., JSON, YAML, syslog) to at least one destination that other tools can consume, such as a log file, the SIEM's event intake or the SIEM data store.

### Rationale
To ensure automation, programmatic access, wide and easy adoption, code reuse.


### Acceptance criteria
Successful validation according to the corresponding test case specification
