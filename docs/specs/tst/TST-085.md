# Open-source licence inspection

This inspection confirms that the repository is distributed under the AGPL-3.0 and that the third-party code it includes keeps its original licence notices (SRS-082).

## Preconditions and setup actions

- A clean checkout of the IDPS-ESCAPE repository at the release under test, with `git` available.
- All commands are run from the repository root.

## Test steps

1. Inspect the licence file:
   ```bash
   head -3 LICENSE
   grep -E '^[0-9]+\. ' LICENSE
   tail -1 LICENSE
   ```
   Read the preamble and terms, and compare them with the AGPL-3.0 published at <https://www.gnu.org/licenses/agpl-3.0.html>.
2. Inspect the authors file and the package metadata:
   ```bash
   cat AUTHORS
   grep '^authors' pyproject.toml
   ```
3. Inspect the licence section of the top-level README:
   ```bash
   grep -n -A3 '^## License' README.md
   ```
4. List the source files that carry a licence notice of their own:
   ```bash
   git grep -l -i -E "SPDX-License-Identifier|GNU General Public|MIT License|Apache License|BSD License" \
     -- sonar radar adbox ':!adbox/mtad_gat_pytorch' ':!*.ipynb'
   ```
   Open each listed file and read its header.
5. Inspect the included MTAD-GAT component:
   ```bash
   head -3 adbox/mtad_gat_pytorch/LICENSE
   ls adbox/mtad_gat_pytorch/licences/
   head -3 adbox/mtad_gat_pytorch/licences/*
   grep -n -B5 'licences' adbox/mtad_gat_pytorch/README.md
   ```

## Expected outcome

1. `LICENSE` starts with `GNU AFFERO GENERAL PUBLIC LICENSE` and `Version 3, 19 November 2007`, lists the 18 sections `0. Definitions.` to `17. Interpretation of Sections 15 and 16.`, and ends with `END OF TERMS AND CONDITIONS`. Its preamble and terms match the published AGPL-3.0 apart from layout.
2. `AUTHORS` lists the developers and states that IDPS-ESCAPE is licensed under the GNU Affero General Public License version 3. The `authors` entry of `pyproject.toml` names the same developers.
3. The README licence section names the copyright holders (itrust Abstractions Lab and itrust consulting), states the GNU AGPL v3.0 and links to `LICENSE` and `AUTHORS`.
4. Exactly the files of `adbox/ad_opensearch_extension/` and `adbox/data_ingestion/__init__.py` are listed, and each keeps the `Copyright OpenSearch Contributors` notice with `SPDX-License-Identifier: Apache-2.0`. No other source file carries a licence notice that conflicts with the AGPL-3.0.
5. `adbox/mtad_gat_pytorch/LICENSE` is the MIT licence of the original MTAD-GAT authors; `licences/` contains `LICENCE_OmniAnomaly`, `LICENCE_TelemAnom` and `LICENCE_pyGAT`, one for each project credited in the component's `README.md`.

The test passes when all five outcomes are observed.
