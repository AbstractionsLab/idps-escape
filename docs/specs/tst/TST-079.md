# RADAR: off-hours model mode on synthetic history

## Preconditions and setup actions

- Same generic preconditions as [TST-055](./TST.html#TST-055).
- `./radar.sh run suspicious_login --ingest true` completed with the shipped configuration: synthetic history written and marked, `SUSPICIOUS_LOGIN_OFF_HOURS_DETECTOR` created and started.

**Test data**: synthetic history written by run-radar.sh suspicious_login --ingest true (alice, bob, oscar in rule mode; trent in model mode with evening work and one 30-event burst at about 02:00 Luxembourg time)

## Test steps

1. From `radar/`, run `poetry run python radar-test-framework/checks/off_hours_model_history.py --env .env`. It runs a historical analysis of the detector over the last 45 days and waits for it.
2. Run `./radar.sh run suspicious_login` a second time, then list the detectors and monitors in **Anomaly Detection** and **Alerting**.

## Expected outcome

1. The script prints:
   - `PASS` for trent's burst, with an anomaly grade above 0 in an interval overlapping it;
   - the number of anomalous intervals on trent's ordinary evenings, with their grades (target 0; recorded in the test result, not enforced);
   - `PASS` for no results for alice, bob and oscar.

   It ends with `[ok]`.
2. One `SUSPICIOUS_LOGIN_OFF_HOURS_DETECTOR`, one `SuspiciousLogin-OffHours-ModelMode-Monitor` and one `SuspiciousLogin-OffHours-RuleMode-Monitor` exist. `SUSPICIOUS_LOGIN_DETECTOR`, if present, is stopped, and `SuspiciousLogin-OffHour-Monitor` is disabled.
