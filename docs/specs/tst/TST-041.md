# RADAR: Suspicious Login Validation

## Preconditions and setup actions
1. Wazuh v4.8.0 is configured with Anomaly Detection Plugin.
2. Docker is installed in the agent endpoint.
3. User with root pivilieges in agent endpoint.
4. The instructions in `soar-radar/suspicious_login/README.md` are followed for setting the environment. 

## Test steps
1. Open Wazuh Dashboards ➝ Anomaly Detection ➝ Monitor.

2. Click “Edit” on the desired Monitor.

3. Open the RADAR Action in the Trigger "Suspicious-Login-Detected".

4. Paste the following sample payload into the test body:
```
{
  "monitor": {
    "name": "{{ctx.monitor.name}}"
  },
  "trigger": {
    "name": "{{ctx.trigger.name}}"
  },
  "entity": "-4324475583306591935",
  "periodStart": "2025-06-26T23:23:00",
  "periodEnd":   "2025-06-26T23:28:00"
}
```

Click “Send test message”. Do not Update the Monitor.

## Expected outcome

On agent (SSO):

- ad_pc_enriched.log contains login events from the anomaly window.

- `sudo iptables -L INPUT -n --line-numbers` shows a new DROP rule for the associated source IPs.

- Keycloak admin panel (http://localhost:8080) shows that the user -4324475583306591935 is disabled (enabled: false).

- /var/ossec/logs/active-responses.log contains an entry for:

  - firewall-drop action, showing source IPs blocked.
  - disable-sso action, showing the SSO user was successfully disabled.
