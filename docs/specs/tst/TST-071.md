# SONAR end-to-end detection with real detectors

## Preconditions and setup actions

1. SONAR dependencies installed: `poetry install --with sonar,test` (the tests import torch).

## Test steps

1. From the repository root, run:
   ```
   poetry run pytest tests/sonartests/test_e2e_detection.py -v
   ```

## Expected outcome

1. A model trained on normal data, with the real MVAD library and with the `pca` backend, flags at least 80 % of the buckets of an injected CPU spike, an alert burst, a silence (no alerts at all) and an interval with a never-seen alert category, and at least twice the share of buckets it flags in the rest of the data.
2. Realtime polling with the real model over overlapping detection windows, delivering to the `jsonl` sink with a watermark, writes at least one anomaly and no `anomaly_id` twice, also after a restart.
