## Preconditions and setup actions
- Docker version 26.0.0
- User with root privileges
- Docker Compose version v2.25.0
## Test steps
1. Clone the Wazuh docker repository in the system as mentioned in section
```
git clone https://github.com/wazuh/wazuh-docker.git -b v4.8.1
```

3. Navigate to the directory since it is a single
node deployment.
```
cd wazuh-docker/single-node
```
4. Provide the group of certificates for secure communication.
  ```
      sudo docker-compose -f generate-indexer-certs.yml run --rm generator
  ```

5. Deploy Wazuh as single-node using docker-compose.
  ```
  sudo docker-compose up -d
  ```
  This could take some time since it would pull all the images.

## Expected outcome

- The following output should be visible on the screen after deployment in
the background (with -d option)

```
✔ Container single-node-wazuh.indexer-1 Started
0.1s
✔ Container single-node-wazuh.manager-1 Started
0.1s
✔ Container single-node-wazuh.dashboard-1 Started
```

- Run the following command and you should see 3 containers running. By `sudo docker ps -a` you shall see
  `wazuh/wazuh-dashboard:4.8.1`,`wazuh/wazuh-manager:4.8.1`,`wazuh-indexer:4.8.1` .

- The Wazuh dashboard is accessible through any browser, on the IP address of the system that it is deployed on.
