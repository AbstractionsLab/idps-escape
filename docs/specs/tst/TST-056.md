# Log volume abnormal growth validation

## Preconditions and setup actions
- RADAR is built according to the scenario [TST-053](./TST.html#TST-053).

## Test steps
1. After starting detector, 30 minutes should be passed for normalizing the training to insert a spike. To insert a spike, in Wazuh Dashboard -> Indexer Management -> Dev Tools, run this query with adapting the timestamp:
```
POST wazuh-ad-log-volume-XXXX.XX.XX/_doc
{
  "@timestamp": "XXXX-XX-XXTXX:XX:00.000Z",
  "data": {
    "log_path": "/var/log",
    "log_bytes": 63210547182
  },
  "agent": { "name": "edge.vm" },
  "manager": { "name": "wazuh.manager" },
  "predecoder": {"program_name": "log_volume_metric"}
}
```

## Expected outcome
1. In the Wazuh Dashboard Discovery page, the rule ID starting with `100309` should be triggered.
2. The email (`EMAIL_TO` from `.env` of [TST-049](./TST.html#TST-049)) specified receives an email about the alert.
