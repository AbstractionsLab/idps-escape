# RADAR configuration and integrations

Software design specifications for RADAR's configuration management (SWD-032), data ingestion (SWD-033), custom rules and decoders (SWD-034), the webhook service (SWD-035), model security (SWD-036), and the integrations with SONAR (SWD-037) and DECIPHER/FlowIntel (SWD-038). The deployment control plane that applies them is specified in SWD-042; the former Ansible role architecture (SWD-031) is inactive.
