# Ransomware attack detection and response

As a security engineer,
I want RADAR to detect ransomware attacks on endpoints through both signature-based patterns and anomalous file system behavior, and then apply the existing risk policy to decide how to react.

1. RADAR shall employ a dual-detection approach for ransomware:
   - Signature-based detection: Monitor for known ransomware indicators including ransom note file creation, suspicious file extensions, and known ransomware process names.
   - Anomaly-based detection: Detect unusual file system activity patterns per endpoint, including abnormal rates of file modifications, mass file renaming, rapid encryption-like entropy changes, and unusual file access patterns.
2. RADAR shall emit a "Ransomware attack detected" alert when either:
   - Signature-based detector identifies ransomware indicators, OR
   - RRCF anomaly detector for file system behavior reports an anomaly score above the configured threshold for metrics indicative of ransomware activity (rapid file modifications, entropy changes, extension changes) per endpoint.
3. The "Ransomware attack detected" alert shall include: endpoint identity, detection method, detector name/ID, timestamp of detection, anomaly score and confidence, affected file paths.
4. For anomaly-based detection, the Wazuh Monitor sends the alert to webhook upon passing the value of risk threshold. For signature-based, the rule should be triggered.
5. RADAR shall run the configured active responses for the triggered rule in the form of email alert, case creation, context collection and logging.
6. The records of active responses are logged.

## Rationale

Ransomware represents a time-sensitive threats to organizational infrastructure, capable of causing complete operational disruption. A hybrid-detection approach is helpful because signature-based detection enables immediate identification of known ransomware families and their artifacts, while RRCF anomaly-based detection identifies zero-day and polymorphic variants by recognizing the fundamental behavioral patterns inherent to ransomware—mass file modifications, rapid encryption, and abnormal file system traversal. This combination provides comprehensive protection across both known and unknown threat vectors, delivering the earliest possible warning.
