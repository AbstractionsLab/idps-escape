# Remote Endpoint Deployment

As a system admin user,
I want to deploy IDPS end-point monitoring solutions on a remote end-point by choosing from multiple configuration options so that I can monitor events on my system's edge/endpoints.

1. Access end-point as root.
2. Deploy end-point components following:

  ```mermaid
  flowchart TB
    S(["Deploy IDPS-ESCAPE end-point"]) --> MN{"Monitor network?"}
    MN -->|yes| FN{"Full NIDS?"}
    MN -->|no| MH
    FN -->|yes| SUR["Deploy CyFORT-Suricata<br/>on the end-point"]
    FN -->|no| MIR["Mirror traffic to C&C<br/>(GRE tunnel)"]
    SUR --> MH{"Monitor host?"}
    MIR --> MH
    MH -->|no| E(["End"])
    MH -->|yes| AL{"Agentless?"}
    AL -->|yes| ALM["Set up Wazuh agentless monitoring"]
    AL -->|no| BS["Run bootstrap-agent.sh<br/>(manager address, token, groups)"]
    BS --> CON["Agent enrolled and connected<br/>to the Wazuh manager"]
    ALM --> E
    CON --> E
                ```

3. Connect local solution to C&C sub-system.

See: `docs/manual/custom_deployments/remote_monitoring/remote_monitoring.md` (integrated and hybrid models) and, for the Wazuh agent, `docs/manual/radar_docs/radar-getting-started.md#3-onboard-an-endpoint`.
