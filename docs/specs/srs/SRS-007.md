# Raw Traffic Capture

As a sys admin user,
I want to capture and forward raw network traffic to the C&C server,
to run NIDS on such a traffic.

1.  Access C&C server.
2.  Deploy C-CyFORT-Suricata.
3.  Identify host capture interface (CI), C&C CI and IP.
4.  On the end-point host, run the port mirroring activation script `docs/manual/custom_deployments/remote_monitoring/idps-escape-port-mirroring.sh` with above arguments; it creates a GRE (`gretap`) tunnel to the C&C CI and mirrors the host's ICMP, TCP and UDP traffic into it.

See: `docs/manual/custom_deployments/remote_monitoring/remote_monitoring.md` (hybrid model).

### Rationale
To collect events for threat hunting and CTI operations, reducing the NIDS overhead and to do customized AD.
