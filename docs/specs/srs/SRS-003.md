# HIDS Agent Deployment

As a sys admin user,
I want deploy HIDS agents on the hosts monitored system so that I can enable the IDPS-ESCAPE HIDS capabilities.

1. Access host to be monitored
2. Install Wazuh Agent
3. Enroll Wazuh Agent in CyFORT-Wazuh manager.
4. Configure Wazuh Agent.

With a RADAR-deployed manager, `radar/radar-agent/bootstrap-agent.sh` performs steps 2 to 4 with a one-time enrollment token minted on the manager (`radar/radar.sh mint-token`); the agent configuration is delivered through its agent groups. See: `docs/manual/radar_docs/radar-getting-started.md#3-onboard-an-endpoint`.

### Rationale
To enable a multi-node deployment of monitoring endpoints host.
