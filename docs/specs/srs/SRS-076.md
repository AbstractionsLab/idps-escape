# SONAR does not write security alerts

SONAR SHALL NOT write documents to the Wazuh alert indices it analyses. Training and detection SHALL use only alerts produced by the monitored environment.

### Rationale

SONAR used to pad sparse history by generating synthetic alerts and indexing them into the live alert indices, then trained on them. That polluted the security record that analysts and other components rely on, and made the model learn fabricated behaviour.

### Acceptance criteria

1. No SONAR command or configuration option writes to the Wazuh alert indices.
2. Configuration keys of the former synthetic-alert generation are ignored with a warning.
