# Indexer Credential Management

As an admin user,
I want to modify the credentials of data indexer for a user,
to improve the security level of the admin password.

1. Access C&C server
2. Access CyFORT-Wazuh manager
3. Update the indexer users' password hashes in `config/wazuh_indexer/internal_users.yml` of the Wazuh Docker deployment and apply them with the indexer's `securityadmin.sh` (upstream Wazuh procedure).

With a RADAR-deployed stack, the first deployment generates unique indexer, dashboard and Wazuh API passwords in `radar/.env`, and `sudo radar/radar.sh rotate-credentials` (`radar/radar_deploy/manager-rotate-credentials.sh`, `radar/wazuh_api/credentials.py`) replaces them: it regenerates `radar/.radar-generated/internal_users.yml`, which `radar/docker-compose.core.yml` mounts into the indexer, and recreates the core stack. See: `docs/manual/radar_docs/radar-operations.md#credentials`.

### Rationale
Maintain/improve the security of IDPS-ESCAPE
