# Open-source licensing

The IDPS-ESCAPE source code and technical documentation SHALL be distributed under the GNU Affero General Public License version 3 (AGPL-3.0), a copyleft open-source licence. Third-party code included in the repository SHALL keep its original licence and copyright notices.

## Scope

This requirement covers the repository as distributed: the source code of SONAR (`sonar/`), ADBox (`adbox/`) and RADAR (`radar/`), the build and deployment scripts, and the documentation under `docs/`. Third-party software that IDPS-ESCAPE uses but does not include (the Wazuh container images pulled by `radar/docker-compose.core.yml`, the Python packages locked in `poetry.lock`) remains under its own licence and is out of scope.

## Requirements

1. The repository root SHALL contain the AGPL-3.0 in `LICENSE`: the preamble and the complete terms and conditions (sections 0 to 17), unmodified.
2. The repository root SHALL contain an `AUTHORS` file that lists the developers and states that IDPS-ESCAPE is licensed under the AGPL-3.0.
3. The top-level `README.md` SHALL name the copyright holders, state the licence and link to `LICENSE` and `AUTHORS`.
4. Source files derived from third-party code SHALL keep the original copyright notice and licence identifier. In v2.2.0 these are the files of `adbox/ad_opensearch_extension/` and `adbox/data_ingestion/__init__.py`, which carry the OpenSearch Contributors notice and `SPDX-License-Identifier: Apache-2.0`.
5. A third-party component included as a whole SHALL ship with its licence files. In v2.2.0 this is the MTAD-GAT implementation in `adbox/mtad_gat_pytorch/`: its own MIT `LICENSE`, and in `licences/` the licences of the projects it credits in its `README.md` (OmniAnomaly and pyGAT, MIT; TelemAnom, Caltech BSD-style).

### Rationale

MRS-001 requires an open-source release under a permissive or copyleft licence. The AGPL-3.0 is a copyleft licence that also covers network use, which matters for components such as RADAR and SONAR that run as services: unlike the GPL, it requires an operator who offers a modified version to users over a network to make that modified source available. Keeping third-party notices intact is a condition of the MIT, BSD and Apache-2.0 licences under which the included code was obtained.

### Acceptance criteria

Successful inspection according to TST-085, which shall confirm:

1. `LICENSE` contains the AGPL-3.0 preamble and complete terms and conditions.
2. `AUTHORS` and the `README.md` licence section name the licence and the authors or copyright holders.
3. Every included third-party file or component listed in requirements 4 and 5 still carries its original notice or licence file.
