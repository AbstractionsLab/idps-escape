# HIDS Agent Management

As a sys admin user,
I want to enabled/disabled HIDS agents deployed on the host monitored system.

1. Access C&C server
2. Enroll/unenroll  Wazuh Agent from CyFORT-Wazuh manager
3. Possibly, remove logs and config files.

With a RADAR-deployed manager: deregistration is `radar/radar_deploy/manager-deregister-agent.sh` (or the RADAR GUI, Deployment → Agent Management), scenario group (un)assignment is `radar/radar_deploy/manager-assign-agent-group.sh` / `manager-unassign-agent-group.sh`, and the agent is removed from the endpoint with `radar/radar-agent/uninstall-agent.sh`. See: `docs/manual/radar_docs/radar-operations.md#agent-enrollment`.

To enable system hosts security posture monitoring
