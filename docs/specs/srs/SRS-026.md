# TIP Data Export

As a user,
I want to export data from IDPS-ESCAPE to a TIP.

RADAR exports alert data for CTI analysis: on each alert, `radar/scenarios/active_responses/radar_ar.py` sends the alert context to the DECIPHER (SATRAP-DL) analyze API, which checks the indicators against MISP, returns a CTI score, and creates a FlowIntel case for tier 1 and above. See: `radar/README.md`.

## Planned extensions

> **Status: planned.** Not implemented as of v2.2.0. The extensions below specify intended behaviour; no code implements them yet.

- Direct export of IDPS-ESCAPE detections to a TIP (e.g., publishing alerts or sightings as MISP events), without going through DECIPHER.

### Rationale
To enable programmatic access, which would also in turn support integration with SATRAP-DL.
