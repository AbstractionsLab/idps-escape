Onboard agent
Mints a short-lived enrollment token, printing a ready-to-paste command for bootstrap-agent.sh. Note: activating and revoking the token each briefly restart the manager, disconnecting all currently-connected agents for a few seconds - this is a real cost of Wazuh's built-in short-lived-token mechanism, not a bug.
Run this on the target endpoint
Deregister agent
Undo of onboarding: removes the agent from the manager entirely, freeing its name/IP for a fresh enrollment. If the Wazuh agent service is still running on the endpoint itself, it will try to re-enroll automatically -- stop it there first if you don't want that.
Checked: the agent record stays in Wazuh (disabled/unreachable) under this same name/IP -- re-onboarding the same endpoint later will need a different name or IP, or you'll need to come back and deregister it properly first. Unchecked (default): the name/IP is freed immediately, so the same endpoint can be re-onboarded right away without any conflict.
Enrollment window (port 1515)
Port 1515 (agent enrollment) is closed by default via a host firewall rule. Open a time-limited window before onboarding a new agent.
